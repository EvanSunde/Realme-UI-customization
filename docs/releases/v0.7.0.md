Install **Evan-Lockscreen-0.7.0.apk** below over 0.6.x. It uses the same package and signing key, so your designs, scenes and shade looks are kept.

## New
- **Shizuku connects by itself.** Grant access once; afterwards the studio reconnects whenever Shizuku is running (at launch, when you return to the app, or when Shizuku restarts).
- **Blur only.** Shade → Blur → *Apply blur* changes just the blur in about a second, without a theme import, and it works in dark mode too. It resets after a reboot.
- **Shade colours only.** *Apply shade colours* no longer touches blur, and the clock apply still keeps your shade. Lock screen, shade colours and blur can now each be changed on their own.
- **10 curated shade looks:** Phone default, Frosted white, Clear glass, Teal frost, Ocean, Mint, Lavender, Rose, Sunset amber and Graphite.
- **AOD display controls** (Tools → Native AOD → Display): turn Always-On Display on or off, and choose All day, Scheduled (with From/Until times) or Power saving. A backup is taken before the first change, and *Restore original* puts everything back.

## Notes
- **Dark mode:** Realme's theme engine ignores notification shade colours in dark mode. This is a firmware rule and can't be changed without root. Colours show in light mode. See `docs/Shade-dark-mode.md`.
- AOD display modes use the same settings Realme's AOD app writes and SystemUI reads. They are checked against firmware 14.20.43 but not yet confirmed on the phone, so please report what you see.
- Update the Shizuku helper: the first launch after updating restarts the helper (version 12).
